# 图表参考

> 本文为[英文版](../charts.md)的中文镜像，逐节对应；如有出入以英文版为准。

图表绘制[解析器](parser.md#通道)产生的数值通道 —— 十六进制帧是 `parsed.<label>`，
文本规则是 `parsed.<name>` 或 `parsed.intN`/`parsed.floatN`。可在 **添加图框** 中新增一个：

| 按钮 | 图表 | 横轴 | 纵轴 |
| --- | --- | --- | --- |
| 时域图 | **时域** | 相对时间，秒 | 数值 |
| 频域图 | **FFT / 频域** | 频率，Hz（0 … Nyquist） | 幅值 |
| 柱状图 | **柱状** | 通道 | 最新值 |

标题默认为 `时域图 N` / `频域图 N` / `柱状图 N`，编号在所有图表之间统一递增。面板依次追加在
彼此下方，可通过悬停工具移除或上移/下移。

## 绑定通道

**数据绑定** 列出所有可选的数值通道，配色与其曲线一致。解析器一产出通道，它们就会出现在列表
中；勾选复选框即加入该序列。

有两条限制值得了解：

- **FFT 与柱状图只能绑定配置中静态声明的通道** —— 即已配置的规则标记（`parsed.int0`、
  `parsed.float1`）、十六进制行标签以及 `bool8` 的位子项。仅因动态 `/nameN` 捕获到标签而存在的
  通道，在 FFT 选择器中会被禁用（`opacity` 变低、not-allowed 光标），因为频谱需要连续的序列。
  时域图则接受它们。
- 绑定尚无数据的通道时什么都不画，而不是画一条水平线；不再存在的绑定会被自动清理。

**统一量程** 把所有已绑定的通道放在同一条纵轴上。当绑定的通道数为一或零时，它被强制开启
（复选框同时禁用）。关闭后，每个通道拥有各自的纵轴范围，并出现一个**纵轴归属**选择器 ——
全部通道 或单个通道 —— 它决定左轴刻度标签与轴标题（`幅值（<channel>）`）描述的是哪个通道的
量程；其余通道仍然绘制，只是不按这些标签换算量程。角标显示 统一量程 / 差异量程 / 调整通道:<key>。

## 图框控件

| 控件 | 位置 | 说明 |
| --- | --- | --- |
| 数据绑定 | 全部图表 | 通道复选框。 |
| 统一量程 | 多通道 | 共用纵轴量程还是按通道各自缩放。 |
| 纵轴归属 | 多通道且关闭统一量程 | 轴标签参照的是哪个通道。 |
| FFT 窗口 | FFT、柱状图 | 分析窗口内的样本数；`min 16`，步长 16，默认 **4096**。 |
| 帧间隔 ms | FFT、柱状图 | 频率轴使用的帧周期。留空即自动识别（占位文案 自动识别）。 |
| AUTO | 头部 | 恢复自动范围 —— 清除手动缩放/平移。 |
| 面板高度 | 拖动上/下边缘 | `heightPx`，默认 220，最小 140。会被持久化。 |
| 打开/关闭、移除、排序 | 头部 + 悬停工具 | 面板的状态与顺序会被持久化。 |

坐标轴的刻度步长取“整齐”的 1/2/5×10ⁿ 值；数值标签按量级保留 0–4 位小数。序列颜色按通道顺序
循环使用七个固定色相（`#1d7af2 #0e9f6e #d97706 #c2410c #8b5cf6 #ef4444 #14b8a6`），结果面板
中的卡片也使用同一套映射。

## 视图导航

所有图表都基于 canvas，并按设备像素比渲染；尺寸变化时会重新绘制。

| 手势 | 效果 |
| --- | --- |
| 在绘图区内拖动 | 横纵平移。横向平移会解除“跟随最新”，视图因此不再跟踪实时数据。 |
| 沿 X 轴拖动 | X 轴缩放（`exp(dx/160)`）。 |
| 沿 Y 轴拖动 | Y 轴缩放（`exp(-dy/160)`）。 |
| 滚轮悬停在绘图区/坐标轴上 | 缩放，每格系数 0.96；绘图区与 X 轴作用于 X，Y 轴作用于 Y。 |
| **AUTO** | 回到自动窗口。 |

X 轴的缩放被限制在 `0.02 … 240`（Y 轴实际上不设边界）。第一次手动手势会把自动量程快照下来，
作为后续缩放/平移计算的基准 —— **AUTO** 恢复的正是它。**FFT 图表始终把频率偏移锁定在 0**，
因此你可以放大某个频段，却不能平移到 DC 之外。

开启“跟随最新”时，时域图会跟踪最新的样本，并在每条曲线末端显示数值标签；FFT 图则改为标注
峰值谱线。

## FFT 行为

频谱由图表自身重采样后的序列计算：

1. 取该通道 30 秒轨迹的最后 `FFT 窗口` 个点（至少需要 4 个）。
2. 施加 **Hann 窗**。
3. 补零至 `n = nextPowerOfTwo(min(4 × samples, 65536))` —— 4 倍过采样用于插值峰点，上限为
   65 536 个复数点（≤ 32 768 条谱线）。
4. 执行原地基-2 Cooley–Tukey 变换。
5. 报告单边幅值谱：`2·|X| / Σwindow`（DC 不减半）。**单位是原始信号单位 —— 峰值幅值，不是 dB。**
6. 第 *k* 条谱线位于 `k × sampleRate / n`；轴止于 Nyquist 频率。

**采样率** 为 `1000 / frame interval`。该间隔取自 帧间隔 ms（若已设置），否则由 SerialCanvas 估算：
共用同一时间戳的帧归为一批，批间隔除以该批的帧数，估算值再用 EMA 平滑（`0.25 previous +
0.75 new`，漂移小于 0.2 % 时保留）。无可测量的对象时回退到 1 Hz。

需要记住的几点后果：

- 只要设备的发送节拍已知，就设置 **帧间隔 ms**。间隔错了会整体拉伸整条频率轴，而时间不规律的
  数据源并不存在唯一正确的答案。
- 幅值只对填满整个窗口的信号才可信；在窗口中途变化的值会被抹开，任何加窗变换都是如此。
- 窗口长度不会被裁剪到实际保留的数据量；对只有 10 个样本的通道使用 4096 点窗口将得不到结果。
- 只缓存最近一次计算过的通道，因此一个 FFT 图上绑定多个通道时，每帧都会重新计算。

## 渲染与保留

图表**不是**无纸记录仪。各窗口是固定的：

| 环节 | 上限 |
| --- | --- |
| 原始数值序列 | 每个通道 180 000 点 **且** 60 秒 |
| 图表轨迹（实际绘制的内容） | 最近 **30 秒**，重索引为均匀网格 |
| 时域自动窗口 | 最近 **10 秒**，最新样本钉在右边缘 |
| 实际绘制的点数 | 约 1.5 × 绘图区宽度（按像素格抽样降点，每格保留最后一个点） |
| FFT 变换 | ≤ 65 536 点 |

由此带来两个影响。其一，图表的 X 值来自**重索引后的网格**（`index × frame interval`），而不是
原始时间戳 —— 抖动被消除了，这正是 FFT 有意义的前提，但该轴只是真实时间的近似。其二，按像素格
抽样降点时每格只保留一个点，而不是 min/max，因此**窄尖峰可能被悄无声息地从曲线上丢弃**，
而数据里依然存在。若某个读数看起来可疑，请放大查看，或按[分析导出](data-formats.md)导出分析表
后用数值检查。

所有图表的渲染合并为每帧一次 `requestAnimationFrame`；另有一个独立的 250 ms 时钟，只刷新状态
文本与时间线进度条。

添加图框 下的 **清空缓存** **不会**删除你的图表 —— 它清除的是实时会话历史（原始字节、日志事件、
计数、派生数据），因此曲线被抹去，而每个图表的配置与绑定完好保留。移除图表要用面板上的 ✕。

## 时间线交互

当你[回放一次采集](user-guide.md)时，图表会依据归档文件自身内嵌的配置重新推导：拖动播放头会在
可见的前缀上重跑解析器并重绘。回放期间添加的图表面板会留在工作集中，而选中某个归档时，其快照
会替换整个图表列表 —— 参见[用户指南 · 时间线的导入与导出](user-guide.md)。
