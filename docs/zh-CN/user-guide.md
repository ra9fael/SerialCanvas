## 连接设备

### 打开端口

**连接设备 | 当前未连接** 会调用 `navigator.serial.requestPort()` 并弹出浏览器的 USB 选择器。按钮文字是实时状态读数，可能显示：

| 文字 | 含义 |
| --- | --- |
| `连接设备 \| 当前未连接` | 空闲状态，点击选择端口。 |
| `断开连接 \| HH:MM:SS` | 已连接；计时器显示已用时长。点击断开。 |
| `正在重连 \| 点击取消重连` | 自动重连循环正在运行；点击可取消。 |
| `重连失败 \| 串口可能被占用` | 重连失败——通常是其他程序占着端口。 |
| `失焦断连 \| HH:MM:SS` | 已因失焦释放，等待标签页重新获得焦点。 |
| `正在应用参数 \| 请稍候` | 正在重新打开端口以应用改动后的帧参数。 |
| `不支持 Web Serial API` | 浏览器不支持 Web Serial。 |

取消 USB 选择器不算错误——日志会记录 `用户取消了串口选择。`，也不弹提示条。

如果上一次会话只授权过**一个**端口，SerialCanvas 会在启动时自动重连到它。已知端口为零个或多个时会等待点击，因为浏览器只允许在用户手势中调用 `requestPort()`。

### 帧参数

| 字段 | 取值 | 默认 |
| --- | --- | --- |
| 波特率 | 任意 ≥ 1 的整数；预设菜单提供 1200 … 921600 | `115200` |
| 数据位 | 8、7 | `8` |
| 停止位 | 1、2 | `1` |
| 校验位 | 无、偶校验、奇校验 | `none` |
| RTS/CTS 流控 | 开/关 | 关 |

接收缓冲区按 `bufferSize: 65536` 申请。

**连接期间改动立即生效**，改波特率也一样：SerialCanvas 会关闭并重新打开端口（一段短暂中断，`正在应用参数 | 请稍候`）。在波特率框中连续输入会防抖 420 ms；离开输入框、按回车、选择预设，或改动数据位/停止位/校验位/流控都会立即应用。若切换过程中端口句柄消失，会得到 `参数未应用`，必须重新连接。

### 调制解调器信号

输出信号用 `setSignals()` 写入，无需重开端口即可生效：

- **DTR**、**RTS**、**BREAK** 开关。
- 启用 RTS/CTS 流控后，RTS 开关由系统接管——它的悬浮提示写着 `RTS/CTS 流控生效时，RTS 由系统自动接管。`
- “失焦自动断连”生效期间，三个输出全部强制拉低。

输入信号用 `getSignals()` 读取，**每 800 ms** 一次，显示为 CTS / DSR / DCD / RI 读数。断开后轮询停止，所以断连后残留的 `-` 属于预期。

### 自动重连

默认开启。端口断开时（`disconnect` 事件、读错误，或因失焦释放），SerialCanvas 会**无退避地无限重试**——唤醒间隔 20 ms，若上一次关闭仍在清理则为 30 ms——并优先使用原端口句柄，回退到 `getPorts()` 中缓存 `getInfo()` VID/PID 匹配的任意条目。前 900 ms 的失败保持静默；之后出现 `重连失败` 提示条。把设备重新插上后，浏览器的 `connect` 事件会自行触发一次重试。

点击连接按钮、取消勾选 自动重连，或手动释放端口，重连都会停止。

> **同一实例上的拔插**：重连需要浏览器仍持有该设备的授权。如果操作系统枚举出新的设备身份，就必须再次使用选择器。

### 失焦自动断连

默认关闭；开启它同时会把**自动重连**打开。标签页被隐藏或窗口失去焦点时，SerialCanvas 关闭端口，以便其他程序占用，并记录日志 `页面失焦，已释放串口连接。` 重新聚焦窗口并恢复焦点后会自动重连。适合同一块板子要和 IDE 烧录工具共用串口的场景。

### 错误

`连接失败` 并附带详情 **串口可能被占用，请关闭其他串口软件后重试**，表示端口被别处占用（或驱动拒绝连接）。关掉另一个工具即可；在 Windows 上这也包括另一个浏览器标签页。

## 串口监视器

日志是 **手动收发 / 终端** 标签页中的*手动*视图。

### 显示选项（连接面板下方的高级选项区）

| 选项 | 作用 | 默认 |
| --- | --- | --- |
| 字符编码 | `UTF-8`、`ASCII`、`Latin-1`、`UTF-16LE`——同时决定 RX 的解码和 TX 文本的编码。 | `utf-8` |
| 换行符设置 | 追加到发送文本末尾的行结束符：`\r`、`\n`、`\r\n`。 | `\r\n` |
| 十六进制接收 | RX 按空格分隔的大写十六进制显示，而不是文本。 | 关 |
| 十六进制发送 | 发送框按十六进制字节解析。 | 关 |
| 显示时间 | 前缀 `[HH:MM:SS.d]`——精确到十分之一秒。在展开的解析布局下隐藏。 | 开 |
| 结尾补换行符 | 把上面那个结束符追加到每次发送之后。 | 开 |

### 行处理与缓冲

字节按 `0x0D` 和 `0x0A` 切分。一次 USB 读取末尾的 `CR` 会被暂存，使跨越两次读取的 `CRLF` 仍然只产生一行，而不是空行。超过 **2048 字节 / 2048 字符** 的行会被拆成多条显示事件——因此一个超长帧可能被解析成两帧（见 [parser.md](parser.md) 的行切分一节）。

实时会话大约保留最近 **8192 个解码字符**（`MAX_LIVE_EVENT_TOTAL_CHARS`）；新数据到达时会丢弃更早的输出。这限制了高波特率下的内存占用，但也意味着**实时视图不是归档**——需要长期保留的内容请用 [REC](#时间线录制冻结回放)。“清空缓存”会重置日志、TX/RX 计数和解析历史。

监视器头部的 **TX** 和 **RX** 是当前会话的字节计数；未连接时显示 `-`，[回放](#回放)期间按可见前缀重新计算。

当日志里有选中文本时，重新渲染会被暂缓，以保证选区不丢。向上滚动（距底部超过 20 px）后会出现回到底部的箭头。

## 终端视图

**终端** 标签页是完整的 xterm.js 仿真，本地内置（不走 CDN）。它面向 shell、AT 指令模块、启动控制台，以及任何需要行编辑的场景。

**终端模式是一条独立通道。** RX 只解码进仿真器并计数，**不会**送入日志、解析器、图表或录制，TX 按键也不被记录。要解析或绘图，先切回 手动收发。

工具栏选项：

| 控件 | 取值 | 说明 |
| --- | --- | --- |
| 换行 | `\n`、`\r\n`、`\r`、无 | 按 Enter 时发送的字节。 |
| 字体 | 默认，另加 Cascadia、JetBrains Mono、FiraCode、Hack、MesloLGS NF、更纱黑体、Noto Mono CJK、Consolas、Courier New | 只可选机器上已安装的字体：检测不到的会置灰并提示 `未检测到该字体，将回退为默认等宽字体`，因为每个字体栈都以 `monospace` 结尾，未安装时渲染结果与默认完全一致。Nerd Font 变体可显示图标。 |
| 字号 | 8–48 px，默认 12 | 终端内按住 `Ctrl` 滚动鼠标滚轮以 1 px 递增；两种方式都会重新计算网格。 |
| 主题 | 跟随应用、黑底绿字、黑底白字、Dracula、Solarized Dark、Solarized Light、One Dark | 与应用主题互不影响。 |
| 回显 | 开/关 | 为不回显的设备提供本地回显。 |

**关闭回显（默认）**——每个按键原样转发给设备，因此 `Ctrl+C`、`Ctrl+D`、方向键和转义序列都能到达你的 shell。只有 Enter 会被改写成选定的换行符。对 shell 以及任何自带回显的设备请保持关闭，否则会看到重复字符。

**开启回显**——SerialCanvas 在本地编辑该行：Enter 提交并发送，Backspace 删除，`Ctrl+U` 清空整行，`↑`/`↓` 翻阅最近 **200** 条命令。其他控制字符以 `^X` 标记透传。

终端每次会话只打印一行提示，说明回显行为。该标签页里的“清空缓存”执行的是 `term.clear()`。

## 发送

发送区位于监视器下方。**立即发送** 是唯一的触发方式——发送框不绑定 Enter，因此可以自由编写多行内容。未连接时发送会弹出提示条 `发送失败 / 串口未连接，无法发送当前内容。`

文本框和十六进制框各自保存**独立草稿**，内部都以原始字节存储：来回切换 十六进制发送 不会丢失或再次损坏另一种模式下输入的内容。

### 十六进制发送

**十六进制发送** 把框内内容按字节解析。输入会被相当积极地规范化：丢掉 `0x`/`0X` 前缀，所有非十六进制字符都当作间隔符，超过两位的片段按两两切开，显示重新按字节对分组（光标位置保持不变）。`AA550102`、`AA 55 01 02`、`0xAA,0x55,0x01,0x02` 和 `aa55 0102` 发送的都是 `AA 55 01 02`。末尾落单的半字节会报 `非法 HEX 字节: <piece>`。上面的换行符选项在十六进制模式下仍会追加结束符字节。

### 三个附加模块

同一时间只打开一个模块面板；发送框下方的磁贴（定时发送 / 触发发送 / 预设发送）用于展开面板，每个磁贴上的小圆点独立于面板是否可见来启用或禁用该模块。三个列表都支持拖拽排序，整个发送区可用其上边缘拖拽改变高度。

**定时发送**——按固定周期轮发的队列。间隔下限 100 ms（默认 1000 ms）；*磁贴*会在每次发送时闪动，低于 500 ms 时常亮。被禁用的条目会跳过；未连接或上一次写入仍在进行时会跳过该次触发。删除最后一行后留下一个空行，而不是空列表。初始示例为 `PING`。

**触发发送**——匹配即应答的规则，每条完整 RX 行求值一次：

| 字段 | 匹配方式 |
| --- | --- |
| 匹配 | 简单的**子串**包含。没有精确匹配，也没有正则选项。十六进制模式下按字节子序列判断。 |
| 应答 | 一旦看到匹配模式就发送；在日志中以 `触发：<desc>` 标记出现。 |

初始示例为 `OK` → `ACK`。

**预设发送**——一次性消息，可选热键和可选期望回复：

| 列 | 说明 |
| --- | --- |
| 发送内容 | 负载。 |
| 期望接收 | 子串（十六进制模式下为字节子序列），或对裁剪后整行的精确匹配。 |
| 描述 | 自由文本；显示在日志标记里。 |
| 快捷键 | **单个字符**，自动转大写，会预选当前聚焦输入框的内容。输入一个字符即启用该模块。 |

模块**启用**时，在文本框之外按下那个裸键就会发送对应预设——不带 Ctrl/Alt/Meta，不支持功能键，且该键必须只匹配一个预设（有歧义的键不做任何事）。日志会标记结果：**1800 ms** 内收到期望回复记为 `√ 预设：<desc>`，超时记为 `× 预设：<desc>`。断开连接时期望状态会被清除。初始示例为 `PING` / `PONG`。

## 时间线：录制、冻结、回放

顶部的条带驱动一个会话模型：一个**实时**缓冲区，加上任意数量的**归档**。归档只保存原始字节和一份设置快照——解析值始终用这些字节配合快照中的规则重新推导，所以即使之后改了规则，归档也能被正确地重新分析。具体结构见[数据格式](data-formats.md)。

### 录制

**REC** 开始一次归档（会自动归档正在进行的录制）并点亮。从那一刻起，每个 RX 和 TX 分片都带上微秒精度的相对时间戳追加进去。停止时保存名为 `REC-<NN>-YYYYMMDD-HHMMSS` 的归档，并弹出提示条 `录制已保存 … 共 N 段`。归档数量与单次长度都没有上限——录完手动停止即可。

### 冻结

条带中部的暂停图标给**实时**视图拍快照，让你在数据继续到达时从容查看：悬浮在中枢上是临时冻结，点击即锁定。只有在实时时间线上、且未处于录制或等待失焦释放时才提供冻结。取消冻结就回到实时。

### 回放

从选择器（`▾`）里选中一份归档。拖动条随即生效：按归档时长分成 1000 步，传输按钮每次步进 ±250 ms、快进 +1000 ms，播放按真实时间推进，监视器、解析结果和图表都反映播放头处的状态。TX/RX 计数按可见前缀重新计算。

选择一份归档**会应用它记录下来的设置**——解析规则、图表配置、串口帧参数、发送模块。这是有意为之（归档会重建自己的分析环境），但也意味着浏览归档时工作配置在你脚下被换掉；回到 实时 或另一份归档时会恢复实时配置。

### 导入与导出

选择器菜单对每份归档提供 导出时间线（**BIN / TXT / CSV**）和 导出解析结果（**TXT / CSV**）。两者都要求选中归档而不是实时缓冲区，无内容可写时以 `无法导出` 拒绝。

- **时间线导出**包含原始字节流和内嵌的配置快照，可以用选择器底部的文件输入读回。导入会校验 `type: 'WSLTimelineRaw', version: 1`，并要求存在内嵌配置，否则报 `时间线缺少配置快照。`。导入不会把字节注入实时会话。
- **解析结果导出**是解析成功帧的平面表——`Seq, Time(ms), <one column per numeric channel>`——供 Excel 或 Python 使用。它用归档自身的规则从原始字节重新推导，并写到与时间线 CSV **相同的文件名**，因此两者都导出时需要把其中一个改名。

格式规范见 [data-formats.md](data-formats.md)。

## 布局、主题与面板

- **宽屏/窄屏。** 当 `window.innerWidth <= 720` 时，应用切换为单列紧凑布局，并浮出配置面板（遮罩会压暗日志）。缩放或旋转窗口后图表会重新渲染以适配。
- **侧栏。** 点击状态胶囊（或在其中按 Enter/Space）会把左列折叠成图标。
- **展开的分析布局** 就是连接面板底部的 解析 模式切换（**图形解析模式**）。它同时会隐藏日志时间戳。
- **发送区高度** 可在 120 px 与监视器剩余高度之间拖拽（默认 252 px），手柄位于磁贴上方；该数值会被持久化。
- **主题** —— 系统菜单中的 跟随系统 / 浅色模式 / 深色模式。`prefers-color-scheme` 会被实时监听，favicon 随主题切换，以保证标签页图标清晰可辨。除非设置了终端皮肤，图表和终端颜色都跟随主题。
- **语言** —— 同一菜单中的 中文 / English / 跟随系统。切换即时生效、无需刷新，并保存在 `serialweb:prefs`；跟随系统读取 `navigator.language`。只有界面会被翻译——已接收的日志行、终端历史、你自己输入的名称以及设备数据都保持写入时的语言。
- **提示条** 10 s 后自动消失，按 key 去重，分为成功/警告/错误三类。
- 系统菜单的 **下载离线版到本地** 会抓取页面及全部资源，下载单个自包含的 `SerialCanvas串口调试.html`，可以放在笔记本或 U 盘里。已经是离线副本（`file://`）时该功能不可用。

## 设置持久化与配置传输

所有内容——串口帧参数、显示选项、解析规则、图表布局与缩放状态、发送队列、终端字体与字号、语言、主题、面板尺寸——都保存在 `localStorage` 的 `serialweb:prefs` 下，写入防抖 500 ms，页面卸载时再刷新一次。字段结构见 [data-formats.md](data-formats.md) 的偏好快照一节。

系统菜单提供三种传输，都基于剪贴板，并且都会先要求一次确认（`此操作会丢失当前设置`）：

| 操作 | 行为 |
| --- | --- |
| 复制配置 | 把 `{type:"SerialWebUserConfig", version:1, exportedAt, userConfig:{…}}` JSON 写入剪贴板。 |
| 粘贴导入 | 读取剪贴板，要求相同的 `type`/`version`，实时应用设置（帧参数有变化时重开端口）。失败提示：`粘贴失败 / 剪贴板中未检测到有效的配置。` |
| 清空配置 | 清除 `serialweb:*` 和旧的 `wsl-*` 存储，断开连接，恢复出厂默认值——语言回到 跟随系统，终端字体与字号回到默认——以及初始的示例发送项，并重新打开版本弹窗。`已还原 / 已恢复默认配置，仅保留示例项。` |

复制/粘贴是让同事获得完全相同的解析器与图表配置最快的办法，也正是时间线归档内嵌的内容。

## 故障排查

| 现象 | 原因与处理 |
| --- | --- |
| `不支持 Web Serial API` | Firefox/Safari，或非安全来源。请在 `https://` 或 `http://localhost` 下使用 Chrome/Edge。 |
| 选择器里没有端口 | 设备未暴露串口接口，或浏览器未获得对它的授权。查看设备管理器；换一根线（只有供电芯的线很常见）。 |
| `连接失败 / 串口可能被占用` | 端口被其他程序占用。关掉它，或开启 失焦自动断连 以便共用。 |
| 字符乱码 | 波特率不对，或 字符编码 与设备不符。 |
| 看不到分行，只有一整块 | 设备从不发送 `\n`/`\r\n`。切分是由换行符驱动的——修正固件，或用 十六进制接收 看原始字节。 |
| 时间戳消失 | 你处于展开的解析布局；时间戳只在收起的监视布局绘制。 |
| 解析器/图表无反应 | 监视器在 终端 上——终端流量绕过分析管线。切回 手动收发。 |
| 规则不再匹配 | 先确认数据源是否变了；输出超过约 8192 字符的进行中会话，请用 录制 归档得到稳定数据集。 |
| 图表有阶梯感或缺尖峰 | 时域图会抽取到约每像素 1.5 个点，并保留每个像素桶的最后一个点——很窄的尖峰可能被丢掉。放大，或导出解析结果表。 |
| 图表上的旧数据消失 | 图表窗口是 30 s 历史（原始序列 60 s，180 000 个点）。长时间运行请用 REC 归档。 |
| FFT 看起来是空的 | 窗口内少于 4 个采样，或自动识别出的帧间隔不对——显式设置 帧间隔 ms。 |
| 快捷键不触发 | 焦点在 input/textarea/select 内，模块被禁用，或两个预设用了同一个键。 |
| 导出中的中文是乱码 | 导出是不带 BOM 的 UTF-8；在 Excel 里用显式的 UTF-8 导入打开 CSV。 |
