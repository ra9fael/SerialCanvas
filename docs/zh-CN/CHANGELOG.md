# 更新日志

> 本文为[英文版](../CHANGELOG.md)的中文镜像，逐节对应；如有出入以英文版为准。

版本号与应用内的 **关于** 弹窗一致。日期格式为 `YYYY/M/D`。
本仓库从 `v0.1.0` 开始打标签；其下的条目保留它们发布时沿用的上游 `1.x` 编号。除这些历史条目外，
每一节都由 `tools/set-version.py` 写入。
编号为 `1.x` 的版本都来自原作者 [电导实验室](https://conductance-lab.xyz)，见[来源与致谢](acknowledgements.md)。

## v0.4.2 — 2026/10/8

- 终端快捷键补齐 **F1–F12**：新增 F5–F12（标准 xterm 序列，与物理键盘行为一致），F1–F4 从
  page 组移入独立的 `fkeys` 组。共 60 键 8 组三行——行输入与导航 / 文本与屏幕 / 流控、中断、
  功能键——并以 1440/1100px 下「行不换行」断言守住条高恒定。
- 组合框输入框不再截断数字：一条老的 `.term-field input[type="number"] { width: 46px }` 规则
  优先级更高，把所有输入框钉在 46px，导致 `1000000`、`33554432` 在任何窗口宽度下都被截断。
  现在每个组合框按自身 max 值的渲染宽度给文本列设底线，▾ 列收窄到 28px，参数行放不下时
  工具栏里的原生下拉先收缩。verify-combo 新增几何断言：组合框必须装得下自己的最大值。

## v0.4.1 — 2026/10/8

- 终端快捷键新增 8 个：^S / ^Q（XOFF/XON 流控，单独成组、不用琥珀色）、^\\（SIGQUIT，
  中断组补齐）、^H（BS 0x08——字节映射早就有，按钮一直缺）、^M / ^J（裸 CR/LF，
  不受换行模式影响）以及 Alt-D / Alt-Backspace（向后/向前删一个词）。共 52 键 7 组，
  两行宽度实测偏差 4.6%。
- 五个纯下拉控件——字号、回滚行数、日志字符、模拟间隔、每次帧数——改为波特率式组合框：
  既能手动输入又能选预设。原先的处理器是成员白名单，输入值不在名单就被静默丢弃；现改为
  按范围钳制（字号 8–48、回滚 100–100 万行、日志 64K–32M 字符、间隔 10–60000 毫秒、
  帧数 1–100），保存过的自定义值刷新后仍在。字号「自定义」的两步交互一并删除。

## v0.4.0 — 2026/10/8

- 项目更名为 **SerialCanvas**：本项目从 SerialWeb `v1.6` 出发、此后独立发展，因此不再使用 fork 的表述。
  `docs/fork.md` 更名为[来源与致谢](acknowledgements.md)，关于弹窗只保留原始项目链接，UI 借鉴说明同时
  写入 [PICOTTY](https://github.com/morpheuslord/PICOTTY)。构建产物（`dist/SerialCanvas.html`）、
  离线包文件名与 Pages 工作流一并随新名；AGPL-3.0 与原始版权不变。
- ☰ 菜单的三组分段按钮（主题 / 语言 / 圆角）现在共享同一套样式：此前两处 CSS `:not()` 列表漏掉了
  `.menu-corner-opt`，圆角按钮被当成列表按钮排版（36px 高、带通用 hover 底色）而非分段按钮。
  滑动指示块自身的 1px 边框此前也未计入 border-box，处于第三位时会滑出分组右边框——
  即截图中的深色模式 / 跟随系统 / 圆润。
- 监视工具栏的模拟状态芯片去掉帧数——它只回答「这批数据是不是模拟的」，收到多少 RX 计数本来就在说。
  两个监视子视图（手动收发与终端）都显示它：芯片位于日志上方的工具栏行里，不在终端画面内部。
- 监视工具栏改为固定两行（标题与操作 / 全部参数字段），取代 1280px 换行、1440px 终端控件独占一行、
  1560px 藏标签这三套补丁；常见窗口宽度下标签不再被截断。

## v0.3.0 — 2026/10/1

- 文档：新增中英双语的[来源与致谢](acknowledgements.md)，并用 `tools/docs-check.py` 校验文档链接、标题锚点与

## v0.2.0 — 2026/10/1

- 新增**语言切换**：系统菜单 `☰` 中提供 中文 / English / 跟随系统。切换即时生效、无需刷新并会被保存；只有界面会被翻译，已捕获的日志行与终端历史保持写入时的语言。
- 终端**字体选择器现在诚实了**：未检测到安装的字体族会被置灰并给出提示，而不是像以前那样静默地渲染成与默认等宽字体完全相同的样子。
- 字体与主题改动在终端隐藏时（手动视图或监视器收起）也能可靠生效——改动会被挂起，待终端重新可见时应用。
- 新增终端**字号**输入框（8–48 px，默认 12），并支持终端内 `Ctrl` + 鼠标滚轮缩放。两者都会被持久化。
- **清空配置**现在同时重置语言与终端字体/字号，并立即重新应用。

## v1.0 — 2026/5/24

- 支持串口监视、设备连接管理、VID/PID 显示、串口参数配置及硬件流控与信号控制。
- 支持深浅主题自动切换及宽屏/窄屏两种布局策略。
- 加入自动重连机制，设备插拔或连接丢失后可尝试恢复。
- 加入失焦自动断连机制，窗口失焦时释放串口，恢复焦点后继续使用。
- 支持图形解析，含文本解析、十六进制结构解析、自动识别规则及实时结果展示。
- 支持时域图与频域图绘制，可绑定解析通道并调整视图范围与量程策略。
- 支持时间线系统，含实时冻结、录制归档、回放、导入导出与解析配置复用。
- 时间线支持导入/导出 BIN/TXT/CSV 原始文件及 TXT/CSV 解析结果。
- 支持手动、定时、触发和预设发送等串口调试工作流。
