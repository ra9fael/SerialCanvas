SerialWeb 由电导实验室（Conductance-lab）创作，本仓库是它的独立分叉；分叉点之前的代码归原作者，两者一律按 AGPL-3.0 授权。

更新日志
v0.3.0 版本 · 26/10/1
  • 界面现在明确标注分叉身份：关于弹窗写清上游项目、分叉提交（e3f9200814，上游 v1.6，2026/9/6）以及各处构建的托管位置；☰ 菜单与弹窗里的链接改为指向本仓库，不再指向原作者的主机。
  • 关于弹窗新增许可证一行，仓库补上 LICENSE：SerialWeb 采用上游声明的 AGPL-3.0 许可证。
  • 线上构建不再发送上游的页面访问统计——该请求只在原作者的主机上发出，因此 GitHub Pages 或 localhost 部署不会产生统计请求。
  • 新增 GitHub Actions 工作流：构建 dist/SerialWeb.html 并作为 index.html 发布到 GitHub Pages。
  • 文档：新增中英双语的分叉来源，并用 tools/docs-check.py 校验文档链接、标题锚点与中英镜像。
v0.2.0 版本 · 26/10/1
  • 新增语言切换：系统菜单 ☰ 中提供 中文 / English / 跟随系统。切换即时生效、无需刷新并会被保存；只有界面会被翻译，已捕获的日志行与终端历史保持写入时的语言。
  • 终端字体选择器现在诚实了：未检测到安装的字体族会被置灰并给出提示，而不是像以前那样静默地渲染成与默认等宽字体完全相同的样子。
  • 字体与主题改动在终端隐藏时（手动视图或监视器收起）也能可靠生效——改动会被挂起，待终端重新可见时应用。
  • 新增终端字号输入框（8–48 px，默认 12），并支持终端内 Ctrl + 鼠标滚轮缩放。两者都会被持久化。
  • 清空配置现在同时重置语言与终端字体/字号，并立即重新应用。
v0.1.0 版本 · 26/9/30
  • 分叉基线：上游 v1.6（提交 e3f9200814）；本仓库把单文件拆成源码分片，并新增了上游没有的 xterm 终端视图。
  • 修复串口接收数据特殊情况下监视器多出空行的问题。
  • 优化设备连接管理中组件的显示效果。
  • 优化图框的部分显示效果和操作逻辑。
v1.5 版本 · 26/7/9
  • "自动硬件流控"更名为"RTS/CTS 流控"，名称更准确。
  • 重构 TX/RX 收发与换行符显示逻辑，优化监视器渲染与事件处理。
v1.4 版本 · 26/7/4
  • 优化页面配色与扁平化设计，浅色/深色模式分离。
  • 优化预设发送交互逻辑，通过开关控制全局快捷键的预设发送。
  • 新增解析配置帮助提示，支持悬浮查看规则说明。
