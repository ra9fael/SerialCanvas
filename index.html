来源与致谢

SerialCanvas 的前身是电导实验室（Conductance-lab）的 SerialWeb（上游 v1.6，提交 e3f9200814，2026/9/6），界面设计另借鉴了 PICOTTY（morpheuslord）。本项目已独立发展，按 AGPL-3.0 授权，原始代码版权归原作者。

更新日志
v0.4.1 版本 · 26/10/8
  • 终端快捷键新增 8 个：^S / ^Q（XOFF/XON 流控，单独成组、不用琥珀色）、^\\（SIGQUIT， 中断组补齐）、^H（BS 0x08——字节映射早就有，按钮一直缺）、^M / ^J（裸 CR/LF， 不受换行模式影响）以及 Alt-D / Alt-Backspace（向后/向前删一个词）。共 52 键 7 组， 两行宽度实测偏差 4.6%。
  • 五个纯下拉控件——字号、回滚行数、日志字符、模拟间隔、每次帧数——改为波特率式组合框： 既能手动输入又能选预设。原先的处理器是成员白名单，输入值不在名单就被静默丢弃；现改为 按范围钳制（字号 8–48、回滚 100–100 万行、日志 64K–32M 字符、间隔 10–60000 毫秒、 帧数 1–100），保存过的自定义值刷新后仍在。字号「自定义」的两步交互一并删除。
v0.4.0 版本 · 26/10/8
  • 项目更名为 SerialCanvas：本项目从 SerialWeb v1.6 出发、此后独立发展，因此不再使用 fork 的表述。 docs/fork.md 更名为来源与致谢，关于弹窗只保留原始项目链接，UI 借鉴说明同时 写入 PICOTTY。构建产物（dist/SerialCanvas.html）、 离线包文件名与 Pages 工作流一并随新名；AGPL-3.0 与原始版权不变。
  • ☰ 菜单的三组分段按钮（主题 / 语言 / 圆角）现在共享同一套样式：此前两处 CSS :not() 列表漏掉了 .menu-corner-opt，圆角按钮被当成列表按钮排版（36px 高、带通用 hover 底色）而非分段按钮。
  • 监视工具栏的模拟状态芯片只在手动收发子视图显示，并去掉帧数——它只回答「这批数据是不是模拟的」， 收到多少 RX 计数本来就在说。
  • 监视工具栏改为固定两行（标题与操作 / 全部参数字段），取代 1280px 换行、1440px 终端控件独占一行、 1560px 藏标签这三套补丁；常见窗口宽度下标签不再被截断。
v0.3.0 版本 · 26/10/1
  • 界面现在明确标注分叉身份：关于弹窗写清上游项目、分叉提交（e3f9200814，上游 v1.6，2026/9/6）以及各处构建的托管位置；☰ 菜单与弹窗里的链接改为指向本仓库，不再指向原作者的主机。
  • 关于弹窗新增许可证一行，仓库补上 LICENSE：SerialCanvas 采用上游声明的 AGPL-3.0 许可证。
  • 线上构建不再发送上游的页面访问统计——该请求只在原作者的主机上发出，因此 GitHub Pages 或 localhost 部署不会产生统计请求。
  • 新增 GitHub Actions 工作流：构建 dist/SerialCanvas.html 并作为 index.html 发布到 GitHub Pages。
  • 文档：新增中英双语的分叉来源，并用 tools/docs-check.py 校验文档链接、标题锚点与中英镜像。
v0.2.0 版本 · 26/10/1
  • 新增语言切换：系统菜单 ☰ 中提供 中文 / English / 跟随系统。切换即时生效、无需刷新并会被保存；只有界面会被翻译，已捕获的日志行与终端历史保持写入时的语言。
  • 终端字体选择器现在诚实了：未检测到安装的字体族会被置灰并给出提示，而不是像以前那样静默地渲染成与默认等宽字体完全相同的样子。
  • 字体与主题改动在终端隐藏时（手动视图或监视器收起）也能可靠生效——改动会被挂起，待终端重新可见时应用。
  • 新增终端字号输入框（8–48 px，默认 12），并支持终端内 Ctrl + 鼠标滚轮缩放。两者都会被持久化。
  • 清空配置现在同时重置语言与终端字体/字号，并立即重新应用。
v0.1.0 版本 · 26/9/30
  • 分叉基线：上游 v1.6（提交 e3f9200814）；本仓库把单文件拆成源码分片，并新增了上游没有的 xterm 终端视图。
  • 修复串口接收数据特殊情况下监视器多出空行的问题。
  • 优化设备连接管理中组件的显示效果。
  • 优化图框的部分显示效果和操作逻辑。
